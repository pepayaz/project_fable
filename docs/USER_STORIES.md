# User Stories — Project Fable

## Purpose

Dokumen ini mendefinisikan user stories untuk Project Fable agar pengembangan tetap berpusat pada kebutuhan user nyata.

## Personas

### Human Capital Staff

Mengelola data staff, status staff, kehadiran, dan catatan evaluasi.

### Division Lead

Mengelola anggota divisi dan membagi tugas.

### Project Lead

Membutuhkan gambaran besar kondisi organisasi lintas divisi.

### Admin

Mengelola data utama sistem.

## Epic 1 — Staff Management

### US-001 Add Staff

As a Human Capital staff, I want to add staff data so that all organization members can be managed in one place.

Acceptance criteria:

- User can input staff name.
- User can input email.
- User can input phone number.
- User can assign department.
- User can assign position.
- User can assign status.
- Staff data is saved successfully.

### US-002 View Staff List

As a Human Capital staff, I want to view all staff so that I can understand the current organization members.

### US-003 Search Staff

As a Human Capital staff, I want to search staff by name or email so that I can find people quickly.

### US-004 Filter Staff

As a Human Capital staff, I want to filter staff by department and status so that I can focus on specific groups.

### US-005 Edit Staff

As a Human Capital staff, I want to edit staff information so that data stays accurate.

### US-006 View Staff Detail

As a Division Lead, I want to view staff detail so that I can understand staff profile, tasks, attendance, and notes.

## Epic 2 — Department Management

### US-007 Create Department

As an Admin, I want to create departments so that staff can be grouped properly.

### US-008 View Department List

As a Project Lead, I want to view all departments so that I can understand the organization structure.

### US-009 View Department Detail

As a Division Lead, I want to view department detail so that I can see members and tasks in the department.

## Epic 3 — Task Management

### US-010 Create Task

As a Division Lead, I want to create tasks so that work can be assigned clearly.

### US-011 View Task List

As a Project Lead, I want to view all tasks so that I can monitor organization progress.

### US-012 Update Task Status

As a Division Lead, I want to update task status so that progress can be tracked.

### US-013 Filter Task

As a Project Lead, I want to filter tasks so that I can focus on urgent or overdue work.

## Epic 4 — Attendance Management

### US-014 Record Attendance

As a Human Capital staff, I want to record attendance so that staff participation can be tracked.

### US-015 View Attendance History

As a Human Capital staff, I want to view attendance history so that staff reliability can be reviewed.

## Epic 5 — Availability Management

### US-016 Add Availability

As a staff manager, I want to record staff availability so that task and event assignment can be planned better.

### US-017 View Availability

As a Division Lead, I want to view staff availability so that I can assign work fairly.

## Epic 6 — Dashboard

### US-018 View Dashboard Summary

As a Project Lead, I want to see dashboard summary so that I can understand organization condition quickly.

### US-019 View Workload Summary

As a Human Capital staff, I want to see workload summary so that I can identify overloaded staff.

## Epic 7 — Performance Notes

### US-020 Add Performance Note

As a Human Capital staff, I want to add performance notes so that staff evaluation is documented.

### US-021 View Performance Notes

As a Human Capital staff, I want to view performance notes so that I can evaluate staff more fairly.

## Future User Stories

- As an Admin, I want users to log in so that access is controlled.
- As a Project Lead, I want to export data to CSV so that I can share reports.
- As a Human Capital staff, I want AI to summarize staff performance so that evaluation is faster.
- As a Division Lead, I want AI to recommend available staff so that task assignment is easier.
