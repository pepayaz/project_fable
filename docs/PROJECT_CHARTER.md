# Project Charter — Project Fable

## Project Name

Project Fable

## Project Summary

Project Fable adalah aplikasi people management untuk organisasi, kepanitiaan, komunitas, dan tim mahasiswa. Aplikasi ini membantu pengelola Human Capital, HR, atau People Management dalam mengelola data staff, divisi, role, tugas, kehadiran, availability, dan evaluasi performa secara lebih terstruktur.

Project ini dibuat sebagai project mandiri berbasis pengalaman nyata dalam aktivitas human capital dan people management.

## Background

Dalam organisasi atau kepanitiaan, pengelolaan staff sering dilakukan secara manual menggunakan spreadsheet, chat group, dan dokumen terpisah. Hal ini dapat menyebabkan data staff sulit dilacak, pembagian tugas tidak jelas, follow-up terlambat, dan evaluasi performa tidak terdokumentasi dengan baik.

## Problem Statement

Pengelola organisasi sering mengalami masalah berikut:

- Data staff tersebar di berbagai file atau chat.
- Sulit melihat staff berdasarkan divisi, role, status, atau availability.
- Task assignment tidak terdokumentasi dengan baik.
- Progress dan performa staff sulit dievaluasi secara objektif.
- Kehadiran dan kontribusi staff tidak mudah direkap.
- Human Capital sulit mengambil keputusan berbasis data.

## Goals

- Membuat aplikasi sederhana untuk mengelola data staff dan divisi.
- Membantu assignment task kepada staff atau divisi.
- Menyediakan dashboard ringkas untuk melihat status staff, task, dan kehadiran.
- Membantu pengelola people management melakukan evaluasi sederhana.
- Menjadi project portfolio yang realistis, relevan, dan dapat dikembangkan lebih lanjut.

## Non-Goals

Pada versi awal, Project Fable tidak bertujuan untuk:

- Mengelola payroll atau gaji.
- Mengelola kontrak legal karyawan.
- Menggantikan HRIS perusahaan besar.
- Menangani compliance ketenagakerjaan profesional.
- Menyediakan fitur enterprise complex seperti multi-company, payroll, tax, atau benefit management.

## Target Users

- Staff Human Capital organisasi mahasiswa.
- HR atau People Management kepanitiaan.
- Ketua divisi atau kepala departemen.
- Project manager komunitas atau organisasi kecil.
- Admin organisasi yang mengelola data anggota dan tugas.

## MVP Scope

MVP didefinisikan sebagai Milestone 1 sampai Milestone 6 pada `docs/ROADMAP.md`.

MVP mencakup:

- Staff management.
- Department/division management.
- Role and status management.
- Task assignment.
- Attendance sederhana.
- Availability tracking.
- Performance notes sederhana (fitur sekunder, P2).
- Dashboard ringkas.
- Basic search and filter.
- Dokumentasi project yang rapi.

## Success Criteria

Project dianggap berhasil pada MVP jika:

- User dapat menambah, melihat, mengubah, dan menghapus data staff.
- User dapat membuat divisi dan menghubungkan staff ke divisi.
- User dapat membuat task dan menugaskannya ke staff.
- User dapat melihat dashboard ringkas tentang staff dan task.
- User dapat mencatat kehadiran staff secara sederhana.
- Project dapat dijalankan secara lokal dengan instruksi yang jelas.
- Struktur kode dan dokumentasi cukup rapi untuk portfolio.

## Constraints

- Project dikembangkan sebagai project mandiri.
- Scope harus kecil dan bertahap.
- Perubahan kode harus minimal dan terarah.
- AI coding agent harus mengikuti dokumen project dan tidak membaca seluruh repository tanpa alasan.
- RTK AI digunakan untuk menghemat output terminal.
- Graphify digunakan untuk membantu agent memahami struktur repository.
