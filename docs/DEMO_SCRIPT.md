# Project Fable: Live Demo Script

This document outlines the step-by-step flow for demonstrating Project Fable's capabilities. Use this script to ensure all key features are showcased efficiently and logically.

## Pre-Demo Setup
- Ensure the application is running locally or on a demo environment.
- Populate the database with realistic but **dummy data** (no real personal information).
- Have demo accounts ready for each role (e.g., `admin@example.com`, `manager@example.com`, `member@example.com`).
- *Note: Never hardcode or display real passwords during the demo.*

## Role-Based Demo Notes
Project Fable utilizes Role-Based Access Control (RBAC). Tailor the demo based on the target audience:
- **ADMIN**: Has full system access. Focus the demo on Data Tools, Users Management, Trash/Restore, and Audit Logs.
- **MANAGER**: Focus the demo on Dashboard, Staff Detail 360, Insights, and team management features.
- **MEMBER**: Focus the demo on My Portal, viewing own data, and basic directory access.

---

## Step-by-Step Demo Path

### 1. Login
- **Action**: Navigate to the login screen.
- **Talking Points**: Briefly mention the secure authentication flow. Log in as an **ADMIN** to show the full feature set.

### 2. Dashboard
- **Action**: Show the main dashboard view after logging in.
- **Talking Points**: Highlight visual analytics, quick overview of total staff, active departments, and recent activities. Emphasize the clean UI and instant data visibility.

### 3. Staff Detail 360
- **Action**: Navigate to the Staff Directory and select a specific staff member.
- **Talking Points**: Show the "360-degree" view. Highlight personal details, role, department, attendance, availability, and performance notes.

### 4. Insights
- **Action**: Open the Insights or Reports section.
- **Talking Points**: Demonstrate data aggregation, trends in attendance, or departmental distribution. Mention how this helps managers make informed decisions.

### 5. AI Briefing & Writing Assistant (Review-Only)
- **Action**: Navigate to the AI features section (or where AI summaries are displayed).
- **Talking Points**: Showcase the AI-generated staff briefings or performance summary drafts. Emphasize that these are **review-only** or "human-in-the-loop" to assist managers and speed up their workflow, not replace them.

### 6. Data Tools (Import / Export)
- **Action**: Go to the Data Tools or Settings area.
- **Talking Points**: Show how easily bulk data can be imported (e.g., CSV upload) and exported for external reporting. This is a key feature for HR/Ops teams.

### 7. Users Management
- **Action**: Open the Users or Access Control settings.
- **Talking Points**: Demonstrate how to invite new users, assign roles (Admin, Manager, Member), and manage active/inactive statuses.

### 8. Trash / Restore (Soft Delete)
- **Action**: Navigate to the Trash or Archive bin.
- **Talking Points**: Explain the soft-delete mechanism. Show how a deleted record (staff or department) can be safely restored without data loss.

### 9. Audit Logs
- **Action**: View the system Audit Logs.
- **Talking Points**: Show the chronological list of system actions (who did what, and when). Emphasize security, compliance, and accountability.
